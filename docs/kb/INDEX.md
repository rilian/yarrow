| [YAR-017] | determinism | all | Radioactive@Home and GQ GMC samples use the wall clock as host time, so the clock-jump check cannot fire for them |
| [YAR-018] | boinc-lifecycle | all | The one-monitor lock fails open when the lock file cannot be opened, for example a non-ASCII path through CreateFileA |
| [YAR-019] | boinc-lifecycle | all | The one-monitor lock covers one BOINC data directory only; several clients on one computer can read one counter twice |
| [YAR-021] | device-selection | all | The firmware, the hub and the udev rule use the pid.codes test USB id 1209:0001 |
| [YAR-022] | build | all | The Makefile and tools/buildall.sh call python, which is missing on many systems that have python3 |
| [YAR-023] | trickle | all | Bins still pending after a calibration change are sent with the new calibration |
| [YAR-024] | trickle | all | Pending bins beyond the first trickle are dropped when the counter's identity, calibration or bin length changes |
| [YAR-016] | determinism | all | The monitor's monotonic clock stops during system suspend on Linux but keeps running on macOS |
